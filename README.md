# Lead Distribution Service

Сервис для распределения обращений лидов между операторами с учетом загрузки и весового распределения.

## Основные концепции

### 1. Оператор
- **Активность**: может быть активен/неактивен для получения новых обращений
- **Лимит нагрузки**: максимальное количество активных обращений (`max_active_leads`)
- **Вес компетенции**: числовой вес для каждого источника (например, 10, 20, 50)

### 2. Лид
- Представляет одного клиента
- Идентифицируется по `external_id` (обязательный) + дополнительно по телефону/email
- Один лид может иметь multiple обращений из разных источников

### 3. Источник (Бот)
- Канал поступления обращений (Telegram, WhatsApp, сайт и т.д.)
- Для каждого источника настраиваются операторы и их веса

### 4. Обращение (Контакт)
- Конкретный факт обращения лида из определенного источника
- Связывается с лидом, источником и оператором (если найден)

## Бизнес-логика распределения

### Определение нагрузки
**Нагрузка оператора** = количество обращений со статусом "new" или "in_progress"

### Алгоритм распределения
1. **Поиск/создание лида** по external_id (приоритет) или телефону/email
2. **Фильтрация операторов**:
   - Активны
   - Не превышен лимит активных обращений
   - Имеют вес для данного источника
3. **Взвешенный выбор**: случайный выбор с вероятностью, пропорциональной весу
4. **Создание обращения** с назначением оператора

### Если операторы не найдены
Обращение создается без назначенного оператора (значение `assigned_operator_id = NULL`)

## API Endpoints

### Управление операторами
- `POST /operators/` - Создать оператора
- `GET /operators/` - Список операторов (с текущей загрузкой)
- `GET /operators/{id}` - Получить оператора
- `PATCH /operators/{id}` - Обновить оператора

### Управление источниками
- `POST /sources/` - Создать источник
- `GET /sources/` - Список источников

### Настройка распределения
- `POST /operator-weights/` - Назначить вес оператора для источника
- `GET /sources/{id}/operators/` - Операторы и веса для источника

### Регистрация обращений
- `POST /contacts/` - Создать обращение (автоматическое распределение)

### Просмотр состояния
- `GET /leads/{id}/contacts/` - Все обращения лида
- `GET /stats/distribution/` - Статистика распределения

## Пример использования

```python
import requests

# Создание оператора
requests.post("http://localhost:8000/operators/", json={
    "name": "Оператор 1",
    "email": "op1@company.com",
    "max_active_leads": 3
})

# Создание источника
requests.post("http://localhost:8000/sources/", json={
    "name": "telegram_main",
    "description": "Основной Telegram бот"
})

# Настройка весов
requests.post("http://localhost:8000/operator-weights/", json={
    "operator_id": 1,
    "source_id": 1,
    "weight": 2.0
})

# Регистрация обращения
response = requests.post("http://localhost:8000/contacts/", json={
    "external_id": "user123",
    "source_id": 1,
    "phone": "+79990001122",
    "message_text": "Здравствуйте, хочу узнать о услугах"
})
```
